# Состояние реализации и ограничения

Сводка сверена с исходным кодом ревизии `f8277e7`.
Приведённые численные результаты относятся к исследовательским сценариям,
зафиксированным в архивных отчётах, и не являются результатами нового запуска.

Полностью сертифицированная конфигурация bootstrap для практического применения
пока не получена. Реализованы исполнители стадий, локальные сертификаты,
планировщик и полный тестовый маршрут.

## Возможности компонентов

| Компонент | Реализовано | Ограничение |
|---|---|---|
| Базовый CKKS | Адаптер, профили, операции, примеры и тесты | Точность зависит от профиля и цепочки вычислений |
| CoeffToSlot / SlotToCoeff | Факторизованное исполнение, подготовка, детерминированные сертификаты | Требуются входные границы, ключи и допустимое расписание |
| EvalRound K=1 | Сертифицированный ciphertext-план для регрессионного профиля | Обычный ModRaise не устанавливает условие K=1 |
| EvalRound K=64 | Синтез, сертификаты полиномов и поиск с учётом backend | Перечисленные кандидаты не удовлетворяют заданному бюджету |
| Sparse bootstrap | Ключи фиксированного веса, encapsulation, lift и восстановление внутри CtS | Полный маршрут отклоняет K>1; отсутствуют конкретные оценки безопасности всех семейств |
| `Bootstrapper` | Подготовка, preflight, исполнение, общий trace и бюджет | Полный тестовый маршрут не даёт production-сертификата |
| Прямой EvalMod | Синтез, подготовка, сертификаты и анализ выполнимости | Для исследованного класса получен отрицательный результат |

## Ограничения полного маршрута

**Домен EvalRound.** Для сгенерированного sparse-ключа выводится `K=h`.
Допустимый вес `h>=2` несовместим с K=1 в полном маршруте. Планировщик
возвращает `UnsupportedEvalRoundDomain` без подмены K.

**Безопасность.** Необходимы конкретные внешние оценки всех требуемых семейств
публичного материала с учётом их зависимостей. Обычный SEAL `tc128`
не заменяет эти свидетельства. При их отсутствии общий уровень неизвестен.

**Общая ошибка.** Локальные сертификаты должны совместно удовлетворять
целевому бюджету. В исследованных полных сценариях граница `1e-10`
не подтверждена. Наблюдаемая ошибка не заменяет доказанную верхнюю границу.

Бюджет `1e-9` каталога кандидатов и целевое значение `1e-10` отдельных
интеграционных исследований относятся к различным контрактам. Ни одно
не является универсальной гарантией точности библиотеки.

## Область отрицательных результатов

Для K=64 проверены 64 кандидата: восемь цифр, два семейства полиномов,
степени 64/128/192/256. В фиксированном backend-сценарии минимальная взвешенная
граница ошибки цифр около `37.0895` превышает требование `1e-2`.
План возвращает `ErrorBudgetExceeded` и не публикует исполнимый граф.
Это ограниченный результат поиска, а не доказательство невозможности EvalRound.
Условия приведены в [разделе EvalRound](evalround.md).

Отрицательный результат прямого EvalMod относится к отдельному классу
компиляторов с явной нормировкой и детерминированными support bounds.
Область утверждения изложена в [разделе EvalMod](evalmod.md).
Результат не переносится автоматически на другие схемы или на весь EvalRound+.

## Проверка актуальности

| Свойство | Тесты |
|---|---|
| Линейные стадии и сертификаты | `test_coeff_to_slot_cert`, `test_slot_to_coeff` |
| Исполнение и границы EvalRound | `test_evalround_backend`, `test_evalround_certificates` |
| K=64 с учётом backend | `test_evalround_k64_synthesis` |
| Sparse-путь и свидетельства безопасности | `test_sparse_bootstrap`, `test_sparse_coeff_to_slot`, `test_sparse_security` |
| Полный тестовый маршрут и отказы | `test_bootstrap_end_to_end` |
| Область результата EvalMod | `test_evalmod_feasibility` |

Команды приведены в [сборке и проверке](build.md).
Изменение перечисленных условий требует обновления этой сводки и соответствующего
тематического раздела. Исходные измерения доступны в [архиве](archive/README.md).
