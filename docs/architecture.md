# Архитектура

WonderFullyHE разделяет исполнение CKKS-операций, подготовку сертифицированных
планов и исследовательский анализ. Границы подтверждённых возможностей приведены
в [состоянии реализации](status.md).

## Библиотеки и зависимости

```text
Приложения и тесты
  ├─ m2424::m2424
  │    ├─ SealAdapter: контекст, ключи, CKKS-операции
  │    ├─ контракты, планы, протоколы исполнения
  │    ├─ CoeffToSlot, EvalRound, SlotToCoeff, Bootstrapper
  │    └─ профили, accuracy, ABFT, отчёты безопасности
  │         └─ Microsoft SEAL
  └─ m2424::evalmod_analysis
       ├─ сертифицирующая подготовка и компиляция планов
       ├─ синтез полиномов, эталоны и анализ выполнимости
       └─ m2424::m2424 + GMP/MPFR
```

Основной публичный заголовок — `include/m2424/m2424.hpp`.
Экспериментальные интерфейсы объявлены отдельно в
`include/m2424/experimental/evalmod_analysis/`.
Некоторые публичные методы подготовки реализованы только в analysis-цели;
условия её подключения приведены в [инструкции по сборке](build.md).

## Основные компоненты

| Компонент | Ответственность |
|---|---|
| `SealAdapter` | Изоляция типов SEAL; контекст, ключи, операции и сериализация |
| `CanonicalEmbeddingReference` | Квадратичный plaintext-эталон в порядке слотов SEAL |
| `CoeffToSlotPlan` | Факторизованное преобразование поднятого шифротекста в две половины коэффициентов |
| `EvalRoundPlusCoeffToSlot` | HP/LP-ветви с общей семантикой и различной нормировкой |
| `EvalRoundPlan` | Математический план извлечения цифр, cleaning и реконструкции |
| `EvalRoundExecutionPlan` | Неизменяемый скомпилированный граф с уровнями, масштабами и границами ошибок |
| `SlotToCoeffPlan` | Обратное преобразование двух половин в шифротекст |
| `Bootstrapper` | Согласованная подготовка, проверка и исполнение полного маршрута |
| Sparse bootstrap | Переключение на ключ фиксированного веса, вывод lift bound и восстановление в первом факторе CtS |
| `accuracy`, `abft` | Метрики ошибки и проверки численной согласованности |

`bootstrapCandidates()` предоставляет каталог целевых конфигураций.
`forecastBootstrapFeasibility` сопоставляет подтверждённые границы с частными
бюджетами. Каталог и калибровка не являются готовыми bootstrap-планами.

## Жизненный цикл плана

Подготовка формирует константы, расписание уровней и масштабов, требования
к ключам и доступные сертификаты. Подготовленный план привязан к фактическому
контексту и входным параметрам. `preflight` проверяет совместимость до исполнения.
Рабочий вызов использует подготовленные данные.

Математический сертификат, готовность отдельного исполнителя и глобальный
сертификат bootstrap различаются. Неизвестная необходимая граница не заменяется
нулём или измеренным значением. Выравнивание масштаба выполняется реальными
арифметическими операциями, без подмены вычисления изменением метаданных.

Подробные контракты: [Bootstrap](bootstrap.md),
[линейные преобразования](linear-transforms.md), [EvalRound](evalround.md).

## Исходные файлы

| Каталог | Содержимое |
|---|---|
| `include/m2424/` | Публичные типы, контракты и интерфейсы |
| `src/core/` | Базовые типы, контракты, метрики и общие внутренние структуры |
| `src/ckks/` | Адаптер SEAL и исполнители EvalRound/bootstrap |
| `src/math/` | Линейные преобразования, эталоны, полиномиальная и точная арифметика |
| `src/planning/` | Подготовка, синтез, бюджеты, отчёты по профилям и безопасности |
| `apps/` | Демонстрации и измерительные приложения |
| `tests/` | Проверки контрактов, backend и интеграционные сценарии |
| `docs/` | Основная документация и архив исследований |

Принадлежность исходного файла к библиотеке определяется
`src/CMakeLists.txt`. В `src/math/` и `src/planning/`
присутствуют как основные, так и опциональные компоненты.
Расшифровка промежуточных результатов для сравнения с эталоном относится
к диагностике и тестам и не входит в исполнение bootstrap.
