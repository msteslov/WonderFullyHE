# Базовая калибровка кандидатов bootstrap

Дата запуска: 2026-07-29. Измерения получены локально через
`bench_bootstrap_candidates`; они не являются доказательством готовности
bootstrap и не заменяют измерения CoeffToSlot, EvalMod, SlotToCoeff и ModUp.

## Методика

- Вход: пять детерминированных векторов из диапазона `[-1, 1]` с крайними значениями.
- Проверки: `add`, `multiply -> relinearize -> rescale` и ротации на шагах
  `1, 2, 4, ...` до половины активных слотов.
- Критерий каждой операции: `max_abs_error <= 1e-9`.
- Временный calibration context не является итоговой modulus chain bootstrap:
  для `N=8192` использована цепочка `[60, scale, 60]`, для больших колец —
  `[60, scale, scale, 60]`.

## Следствие

Ни один кандидат пока не получает статус `validated`: отсутствуют подтверждённые
границы ошибки ModUp, CoeffToSlot, EvalMod и SlotToCoeff. Следующий эксперимент
должен измерять реальную ошибку и число ротаций отдельного CoeffToSlot для
сначала `precision_8192_s59` и `precision_16384_s59`. Вариант
`throughput_16384_s55` не следует брать первым: его ошибка одной ротации уже
составляет заметную долю итогового бюджета `1e-9`.
