# Архив исследований

Архив содержит отчёты о конкретных состояниях реализации и экспериментах.
Он организован по предметным областям. Действующие интерфейсы и ограничения
описаны в [основной документации](../README.md) и [сводке состояния](../status.md).

Каждая запись указывает последнюю ревизию исходного отчёта до реорганизации
документации. Это идентификатор версии текста, а не обязательно ревизия запуска
эксперимента; исходные параметры и revision notes сохранены в самом отчёте.

Численные таблицы, зарегистрированные запуски и исходные выводы сохранены.
Утверждения об отсутствии компонентов, команды и планы дальнейших работ
относятся к описанному этапу. Они не устанавливают текущий статус библиотеки.
Названия разделов и обозначения спецификаций унифицированы. Язык, параметры
и результаты исследовательской части сохранены для проверяемости.
