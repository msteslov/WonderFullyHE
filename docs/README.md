# Документация WonderFullyHE

Документация описывает устройство библиотеки, действующие контракты и границы
подтверждённых результатов. История отдельных изменений не требуется для чтения.

Начальное знакомство: сборка, базовые операции, архитектура и состояние реализации.
Для исследования bootstrapping: Bootstrap, линейные преобразования и EvalRound.
EvalMod представляет отдельное направление анализа modular reduction.

## Терминология

| Термин | Значение |
|---|---|
| Шифротекст (`ciphertext`) | Зашифрованный объект CKKS с определёнными контекстом, уровнем и масштабом |
| Масштаб (`scale`, Delta) | Множитель, связывающий целочисленное представление и семантическое значение |
| План | Описание операций и условий их выполнения |
| Подготовленный план | План с константами и привязкой к фактическим параметрам исполнения |
| Сертификат | Границы и свидетельства, полученные при явно указанных предположениях |
| Наблюдаемая ошибка | Результат сравнения с эталоном в конкретном эксперименте |
| `Unknown` | Отсутствие необходимой подтверждённой границы или свидетельства |

`Certified` трактуется в пределах объекта, которому принадлежит статус.
Сертификат математического плана, готовность исполнителя и сертификат полного
bootstrap имеют различные условия и не взаимозаменяемы.

## Порядок актуализации

Основные страницы описывают текущее состояние исходного кода. Изменение API,
контракта или ограничения сопровождается обновлением соответствующего раздела
и, при необходимости, сводки состояния. Команды сборки сосредоточены в `build.md`.

Отчёты о численных экспериментах хранятся в `archive/`. Для каждого нового отчёта
указываются ревизия, параметры, способ воспроизведения и область применимости.
Наблюдения, доказанные границы и входные предположения фиксируются раздельно.
Исторический результат не переносится на текущую реализацию без проверки.

Публичные объявления находятся в заголовках `include/m2424/`.
[HTML-справочник](build.md) включает эти заголовки, основные страницы
и отдельно обозначенный архив исследований.
